A richer computational organism

Each agent has a fully recurrent neural controller, temporary memory state, finite energy, stable identity and ancestry. Successful task responses alter its energy. Reproduction copies and mutates inherited weights into a new individual.

Birth is supplied by the simulator. These agents did not emerge from the BFF soup. The controller has no gradient training or lifetime relearning. This is a computational lesion experiment with untested biological validity.

Frozen-weight task assays

Remember an initial cue through distractors, then obey an explicitly supplied normal/reversed rule on go trials or withhold on no-go trials. Assay memory is reset per episode. Uniform three-action chance is 33.3%; always withholding is 25%; static left/right choice is 37.5% in expectation.

Intervention and inheritance

The designated region is the final quarter of recurrent units. A focal intervention disables units within that region; the control disables the same number across all recurrent units. This partition has no established executive specialization.

Acquired masks follow the injured individual's stable ID. New offspring have new identities and healthy masks. A falling injured population can reflect replacement; it is not evidence of repair.
