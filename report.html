What this tests

Does disabling part of a functioning computational system change copying or task performance? Does the location of damage matter when the number of disabled sites stays constant?

The soup has no explicit reproduction reward. Copying emerges through program execution if it emerges at all. The separate control model is trained on explicit tasks and uses hand-designed modules.

The two models are separate experiments. The learned controller did not evolve out of the soup. Neither result establishes consciousness, subjective trauma, or a biological model of traumatic brain injury.

Damage has a precise meaning

Soup: a persistent mask disables execution at designated tape positions. It belongs to a resident substrate slot. Copying code does not copy the mask.

Controller: acquired lesions disable computational units. The mask persists across episodes and stays separate from learned weights, temporary state, and offspring.

A contiguous tape lesion is spatially focal, not a functionally localized frontal lesion. The controller provides an explicit, engineered control module.

The next experiments

2 · LocalizationMeasure functional importance before choosing a lesion. Add sensory, memory, motor, and random ablation controls.
3 · RecoverySeparate relearning by the same injured individual from population replacement by an uninjured lineage.
